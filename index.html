🔄 Account & Multi-Device Sync

Sign in to sync all your data across devices in real time. Powered by Supabase (free).

Setup (one-time, free):
1. Go to supabase.com → New project (free)
2. Settings → API → copy Project URL and anon public key
3. SQL Editor → run: CREATE TABLE nx_sync (id uuid DEFAULT gen_random_uuid() PRIMARY KEY, user_id uuid REFERENCES auth.users NOT NULL, key text NOT NULL, value text, updated_at timestamptz DEFAULT now(), UNIQUE(user_id, key)); ALTER TABLE nx_sync ENABLE ROW LEVEL SECURITY; CREATE POLICY "Users own data" ON nx_sync USING (auth.uid()=user_id);
